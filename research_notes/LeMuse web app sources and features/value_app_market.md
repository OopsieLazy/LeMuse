# Market scan: a simple web app for seeing values (greyscale, invert, notan/posterize, value check), and what would make one sellable in 2026

Research date: 2026-11-23. Sources were fetched or searched on that date unless a date is given. App Store pages were fetched from the US store. Reddit could not be fetched (the fetch tool is blocked from reddit.com) and no Reddit threads appeared in any search, so community voice comes from WetCanvas/Adobe/Polycount/Hacker News/App Store reviews/blogs instead (see Gaps).

## 1. Who already does this: features, pricing, ratings

### Takeaway
Basic greyscale, notan and posterize is now a commodity. At least eight free browser tools (most say they process on-device) and a dozen phone apps already do it, and new ones appeared in 2025–2026. Paid products charge little: about $1–$24 one-time or $2–$15 a year. The market leader, Value Study, has about 3.4K US ratings at 4.8★. The paid products that work are mobile apps with a live camera, or bundles (colour mixing plus values plus grid), not single-purpose web converters.

The privacy label says no data is collected. — [App Store](https://apps.apple.com/app/id6769758248). *This is the closest existing product to the "phone held over your painting, compared with the reference" idea.*

**Browser / web tools (the direct competitors for a web app)**
- **ArtistAssistApp** (Eugene Khyst). An open-source web app (**AGPL-3.0**, TypeScript): Kubelka-Munk paint mixing, tonal values, outlines, grid, limited palette, simplification. No login, and it works offline (dev.to post titled "now available offline"). Paid **Patreon membership** "adds all 250+ paint brands," higher-quality outlines, background removal, colourisation, styles, cloud sync, and **ad-free** use. Show HN on **25 Oct 2023: 168 points, 52 comments**. The author: "The app doesn't use AI. Just good old math." A critic: "Picking colors from a photograph is a quick way to choose muddy colors." — [Hacker News](https://news.ycombinator.com/item?id=38011432). One aggregator cites a $5/mo Patreon tier (unverified). — [search summary](https://news.ycombinator.com/item?id=38011432)
- **TonalValueTool.com**: free, no signup, a "Buy us a coffee" link, and "all image processing is done locally on your device." 2–16 levels, Standard/Pixel/Region (morphological smoothing) styles, a hex/oil-paint base colour (e.g. Van Dyke Brown), a colour-temperature base, a notan generator, and a greyscale converter. **No camera, CIELAB/Munsell, % scale or compare.** — [tonalvaluetool.com](https://tonalvaluetool.com/)
- **ArtistTools.org**: **70 free tools** (14 value/tone tools including Value Checker, Value Study Maker, Notan Generator, Underpainting Generator; plus colour, practice, print tiler, pricing calculators). No paid tier, no ads, in-browser processing. Made by Artisticmasterclass.com (a course business), so it works as a lead-generation funnel. — [artisttools.org](https://artisttools.org/)
- **Notana** ("The Painter's Eye"): a Chrome/Edge/Firefox **extension**. Greyscale, 3–5 value groups, posterize, block-in polygons, edges, palette, composition grids. All tools free; an optional **$95/yr settings sync** unlocks no tools. "450+ painters," 4.8/5, local processing. — [usenotana.app](https://usenotana.app/)
- Others (all free, found via search): SketchKit Notan Maker (2–8 tones, download), LlamaGen Value Study Maker (an AI-image company using the tool as an SEO page), Critico (3-tone view of an uploaded painting), Art in Context notan generator, Made Good Designs notan generator (2 values for notan, 3–5 for a study). — [search results](https://sketchkit.art/simplifier), [llamagen.ai](https://llamagen.ai/tools/value-study-maker), [critico.art](https://critico.art/blog/notan-art), [artincontext.org](https://artincontext.org/notan-generator/), [madegooddesigns.com](https://madegooddesigns.com/tools/notan-generator/)

**General-purpose substitutes**
- **Photopea** (a free web Photoshop) can do any greyscale or posterize check. Ads make up most of its revenue, plus an ad-free subscription. — [Indie Hackers](https://www.indiehackers.com/post/making-3m-per-year-with-a-free-product-axW4u1vB6C8f91Z3Lxu5)
- **Procreate** has no dedicated value view. The common workaround is a white layer in "Saturation" blend mode, toggled on and off. — [Proko community](https://www.proko.com/community/topics/how-is-color-and-greyscale-connected), [Procreate handbook](https://help.procreate.com/procreate/handbook/layers/layers-blend). **Clip Studio** has a user-made "Easy Value Checker" asset (listing shows count 4,508, metric unclear). — [Clip Studio Assets](https://assets.clip-studio.com/en-us/detail?id=2206287). **Photoshop** users use B&W adjustment layers or a black Color-blend fill, and testers note "every single way differs in some way from the other." — [Adobe Community](https://community.adobe.com/t5/photoshop-ecosystem-discussions/so-what-s-the-best-most-accurate-way-to-do-a-grayscale-check-in-photoshop/m-p/13661425)
- Physical tools still sell: a "Grayscale & Value Finder" card costs $5.99 at Wallack's. — [wallacks.com](https://wallacks.com/collections/new-products/products/grayscale-value-finder)

### Inferences
- A web app that only does greyscale, invert and notan enters a crowded, **free, client-side** field. Several sites (artisttools.org, tonalvaluetool.com, LlamaGen, SketchKit) look SEO-built in 2025–26 and already make the same "no upload, private" claim, so privacy alone no longer sets a product apart.
- Willingness to pay is proven **on mobile with a live camera**: Value Study has about 3.4K ratings, and Painting Mirror, Color Study and Overgrid charge for pro tiers. A typical price is **about $7–$18 one-time or $2–$15 a year**.
- Gaps the apps leave open: **exact, perceptual (CIELAB L\*) numeric values with a stable/averaged readout** (See Value's complaint), and **reference-vs-painting value comparison as a core flow**. Today it exists only as a basic side-by-side (Painting Mirror, ValuePal, Painter Values Check, Value Study Assistant's slider). None of the web tools has a camera mode or a compare flow.

### Gaps
- No Google Play ratings or download counts (the Play page didn't render). No traffic figures for any web tool (Similarweb not accessible).
- Proko: no dedicated value tool found. Adobe Capture, PureRef and ArtWorkflow/MyPaintColors weren't verified in this pass (no time left). PureRef is known as a reference board with a greyscale toggle, but that is unverified here.
- Color Study's Pro price is not on its home page.

## 2. What artists say they want or miss

### Takeaway
I couldn't get direct Reddit quotes (blocked). The available voices ask for **simplicity**, **trustworthy and stable value readings**, **comparing the scene or reference with their own painting**, apps that keep working (abandoned apps break), and **no ads or junk**. There is a clear anti-generative-AI sentiment.

### Cited Findings
- Simplicity: "Just right. Just enough features but not so many that it gets confusing." — [Value Study App Store review](https://apps.apple.com/us/app/value-study/id1546616127)
- Stable readings: "Is there a way to reduce the sensitivity a bit or average out the readings over a second's time?" — [See Value App Store review](https://apps.apple.com/us/app/see-value/id1312532225)
- User-controlled threshold: a reviewer asked to move the black/white split off 50/50, and the developer added a threshold slider. — [See Value App Store](https://apps.apple.com/us/app/see-value/id1312532225)
- Compare painting vs subject: WetCanvas posters photograph the work in progress in natural light and switch it to monochrome, or drop saturation and adjust brightness and contrast so the phone photo matches the painting. 1 Touch Value Finder was valued for photographing both scene and painting and comparing shapes. — [WetCanvas (via search; fetch returned 403)](https://www.wetcanvas.com/forums/topic/an-easy-way-to-check-the-values-in-your-painting/)
- Accuracy distrust: Hue/Sat −100 is "the least accurate" method, and the different greyscale methods disagree. — [Adobe Community](https://community.adobe.com/t5/photoshop-ecosystem-discussions/so-what-s-the-best-most-accurate-way-to-do-a-grayscale-check-in-photoshop/m-p/13661425); [Polycount](https://polycount.com/discussion/224315/painter-what-is-the-best-way-to-value-check-grey-scale)
- Ad hostility: "better free alternatives… without being crushed by ads"; "bogus app." — [Painter Values Check reviews](https://apps.apple.com/us/app/id1531149807)
- Abandonment: ValueViewer broke after an iPadOS update and "the developer never replied" (forum snippet). — [DPW Art Talk via search](https://arttalk.dailypaintworks.com/t/massing-values-and-proportions-app/1297)
- Anti-AI: Procreate's Aug 2024 no-generative-AI pledge was widely praised by artists. — [TechCrunch, 19 Aug 2024](https://techcrunch.com/2024/08/19/procreate-takes-a-stand-against-generative-ai-vows-to-never-incorporate-the-tech-into-its-products); ArtistAssistApp markets itself with "doesn't use AI. Just good old math." — [HN](https://news.ycombinator.com/item?id=38011432)
- Pedagogy pushback: "Picking colors from a photograph is a quick way to choose muddy colors" (the risk of a tool encouraging shortcuts). — [HN](https://news.ycombinator.com/item?id=38011432)

### Inferences
- Messaging that will land: "no AI, just maths," "no ads," "works offline," "your photo never leaves your device," and stable numbers.
- Comparing your painting with the reference is a real workflow people improvise with phone photos. That makes it the strongest evidence-backed feature to build.

### Gaps
- No direct r/painting, r/learnart, r/oilpainting or YouTube-comment quotes (Reddit fetch blocked; YouTube comments not fetchable). Worth a manual check by the owner before the acceptance examples are written.

## 3. Differentiators, with evidence

### Takeaway
The features that could set the app apart, with evidence: (1) a **live camera compare** of your painting against the reference on the same scale; (2) **exact perceptual values** (CIELAB L\* shown as a %, a 1–10 or Munsell-style step, averaged so it doesn't jitter); (3) a user-set threshold/Otsu notan; (4) a **PWA that works offline, needs no install, sends nothing, has no AI**; (5) print grids. A colour-temperature map and limited palettes already exist in rivals, so they only match the competition.

### Cited Findings
- A live camera value view exists only in native apps (Value Study Live Filter, See Value, Painter Values Check, Painting Mirror). None of the web tools found has one. — [valuestudy.app](https://valuestudy.app/llms-full.txt), [See Value](https://apps.apple.com/us/app/see-value/id1312532225), [Painter Values Check](https://apps.apple.com/us/app/id1531149807), [Painting Mirror](https://apps.apple.com/app/id6769758248), [tonalvaluetool.com](https://tonalvaluetool.com/)
- Compare features in rivals are basic: Painting Mirror has a free side-by-side and a paid before/after study capture; Value Study Assistant has a slider against the original; ValuePal compares a tapped value with a reference; Value Study has no compare. — sources above
- Numeric scales: Painting Mirror has a 1–10 Value Picker (paid); See Value shows the exact lightness at a point; Value Study has a customisable value scale (direction, numbering, labels). — [Painting Mirror](https://apps.apple.com/app/id6769758248), [See Value](https://apps.apple.com/us/app/see-value/id1312532225), [valuestudy.app](https://valuestudy.app/llms-full.txt)
- Temperature maps already exist (Color Study, Overgrid, Painting Mirror, TonalValueTool's colour-temperature base). — [colorstudy.app](https://colorstudy.app/), [Paintingstack](https://paintingstack.com/blog/best-grid-apps-for-artists)
- Grids with print and a large print tiler exist free on artisttools.org. Value Study prints and has a diagonal grid. — [artisttools.org](https://artisttools.org/), [App Store](https://apps.apple.com/us/app/value-study/id1546616127)
- Offline PWA: ArtistAssistApp already works offline. — [dev.to](https://dev.to/eugene-khyst/artistassistapp-is-now-available-offline-and-has-other-cool-new-features-1ke6)
- Limited palettes (e.g. Zorn) and paint mixing are covered by ArtistAssistApp (Kubelka-Munk, 250+ brands) and Color Study. — [Patreon](https://www.patreon.com/artistassistapp), [colorstudy.app](https://colorstudy.app/)

### Inferences
- The most defensible wedge for a web app is **"hold your phone over your painting: see its values next to the reference's values, on the same numeric scale, with mismatches highlighted."** The browser camera (getUserMedia) makes this possible without an install. Lighting, glare and auto-exposure make matching hard (WetCanvas posters already fiddle with brightness to match), so an exposure/white-point calibration step (e.g. tap the white of the canvas) would be a real, hard-to-copy improvement. This is my own design inference and has not been validated with users.
- Proportional divider, sight-size and Munsell steps are niche. They suit a power-user Pro tier, not the headline.

### Gaps
- No evidence found on demand for Munsell-specific steps, or for proportional-divider tools in web form.

## 4. Monetisation evidence for small art-tool apps

### Takeaway
What works at small scale: a **one-time unlock of about $5–$20** (with optional tips), or **free + Patreon** to fund an open-source tool. Ads work only at Photopea-scale traffic and artists resent them. Expect low single-digit % conversion on any freemium funnel. I found no public revenue figures for any value-study tool.

### Cited Findings
- One-time / lifetime pricing is the norm among painters' apps: Value Study (about $6.99 lifetime per the developer, or $23.99 per the US IAP list), Painting Mirror ($17.99 permanent), ValuePal ($14.99), Grid Painter ($2.99), CopyIt ($19.99), Overgrid (one-time). — sources in §1
- Tips are built into a leading app: Value Study sells $2.99/$9.99/$24.99 "supporter" IAPs. — [App Store](https://apps.apple.com/us/app/value-study/id1546616127)
- Donations: TonalValueTool uses "Buy us a coffee." — [tonalvaluetool.com](https://tonalvaluetool.com/)
- Patreon + open source: ArtistAssistApp (AGPL) gates its brand database, AI-free extras, sync and ad removal behind Patreon. No patron count is shown. — [Patreon](https://www.patreon.com/artistassistapp)
- Selling sync rather than features: Notana charges $95/yr for settings sync only and unlocks no tools. Its scale is "450+ painters." — [usenotana.app](https://usenotana.app/)
- Lead generation: artisttools.org gives away 70 tools to feed a course business. — [artisttools.org](https://artisttools.org/)
- Ads: Photopea reportedly earns about $200K/month mostly from ads (about 90% of revenue), with the remainder from an ad-free subscription and API licences. Reported totals range from $1M (2021) to $3M (2024), and the figures are self-reported or estimated. — [Indie Hackers](https://www.indiehackers.com/post/making-3m-per-year-with-a-free-product-axW4u1vB6C8f91Z3Lxu5), [AIN 2021](https://en.ain.ua/2021/04/15/photopea-history), [Indie Hackers](https://www.indiehackers.com/post/generating-200k-monthly-revenue-with-an-online-photo-editor-ad36e6538e). Artists resent ads in small tools. — [Painter Values Check reviews](https://apps.apple.com/us/app/id1531149807)
- Conversion benchmarks (B2B SaaS, not art apps): 3–5% free-to-paid is "good" and 8–12% "great". ChartMogul's 2026 median is 8%, but few products reach it. — [ChartMogul](https://chartmogul.com/reports/saas-conversion-report/). First Page Sage's agency-client average is 3.7% (2021–2025 clients; may not generalise). — [First Page Sage](https://firstpagesage.com/seo-blog/saas-freemium-conversion-rates/)
- Web payment rails for one-time unlocks: Lemon Squeezy (merchant of record, handles VAT) and Gumroad. — [freeCodeCamp](https://www.freecodecamp.org/news/ultimate-tool-stack-for-indie-hackers/)

### Inferences
- Rough sizing (inference): with a 1–3% one-time conversion at about $8, 10K monthly users would bring in roughly $800–$2,400 a month. Reaching 10K a month for a new SEO-dependent tool against many free rivals is uncertain. A realistic first year for a tiny maker is pocket money to a few hundred dollars a month unless one feature (the camera compare) earns word of mouth.
- Ads conflict with the "calm, private, no-junk" positioning and need very high traffic to pay. Avoid them.

### Gaps
- No public revenue, MRR or patron counts for Value Study, ArtistAssistApp, Color Study or any notan web tool. No art-tool-specific conversion data.

## 5. Is "more sellable than the desktop app" plausible? Reach and friction: web vs an unsigned Windows installer

### Takeaway
On **reach and friction, yes**: a web/PWA tool avoids SmartScreen, runs on the phone at the easel, and can be found through search. On **revenue, it is only modestly so**, because the web niche is crowded with free tools. The sellable part is a phone-first camera-compare feature, not the greyscale converter.

### Cited Findings
- Unsigned files start with zero SmartScreen reputation on every new version. Microsoft says to sign every release. **Smart App Control on Windows 11 blocks unsigned files** that lack positive reputation. Microsoft's recommended Artifact Signing costs about $10/month. EV certificates no longer guarantee no warning. — [Microsoft Learn: SmartScreen reputation](https://learn.microsoft.com/windows/apps/package-and-deploy/smartscreen-reputation), [Microsoft Learn: code signing options](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/code-signing-options)
- Even after paying for signing, an indie developer reported new users "still see a scary blue warning." — [Indie Hackers](https://www.indiehackers.com/post/we-paid-for-windows-code-signing-and-new-users-still-see-a-scary-blue-warning-d3dab1188f)
- The Microsoft Store route is free and shows no warning. SignPath offers free signing for qualifying OSI-licensed open-source projects. — [Microsoft Learn](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/code-signing-options), [McpManager docs](https://jerrettdavis.github.io/McpManager/CODE_SIGNING.html)
- Mobile use at the easel is the dominant pattern for value checking: the live camera apps, and WetCanvas posters photographing work in progress with phones. — §1 and §2 sources
- SEO: the search term space ("notan generator," "value study maker," "image simplifier") already has many dedicated landing pages, from tonalvaluetool.com, artisttools.org, LlamaGen, SketchKit, colorstudy.app/notan-generator, Art in Context and Made Good Designs. — [search results](https://tonalvaluetool.com/notan-generator), [colorstudy.app/notan-generator](https://colorstudy.app/notan-generator)

### Inferences
- Compared with LeMuse (a Windows-only unsigned installer; streaming reference images, which can't be sold on top of museum/Are.na content), the web app has far lower friction and a clearer paid hook (the user's own photos, with full pixel access). So "more sellable" is plausible. But "sellable" here means small one-time unlocks or tips, not a business, unless distribution (an art educator or YouTube partner, or the friend's domain audience) is solved.
- Wrapping the PWA for the app stores later (where Value Study earns) may matter more than the web for revenue.

### Gaps
- No Google Trends or keyword-volume data was accessible (no keyword tool available; searches returned no volumes). The owner should check Google Trends and Keyword Planner for "notan generator," "value study," "grayscale converter for artists," and "value checker."

## 6. MIT licence and selling; open-core examples

### Takeaway
Selling convenience on top of freely available code works for art software: Krita sells GPL builds on Steam and the Microsoft Store, Aseprite sells source-available binaries, ArtistAssistApp combines AGPL with Patreon. With MIT, anyone can rehost the app commercially, so the moat is the brand, the domain, updates and support, not the code. To charge for a web app, keep the paid parts server-side, or use a separate licence (AGPL or source-available) for the web app's repo.

### Cited Findings
- **Krita** (GPLv3) sells the same GPL software on the Windows Store and Steam. Store sales "basically now fund [the maintainer] to work full-time," and in 2021 were "the main source of income for sponsoring development." Free downloads continue at krita.org (about 30K a week in 2018). Its 2023 price was $9.99 after briefly trying $14.99. — [Krita 2018](https://krita.org/en/posts/2018/krita-in-the-windows-store-an-update/), [Krita 2021](https://krita.org/en/posts/2021/bumping-the-store-prices-for-krita-5-0/), [Krita 2023](https://krita.org/en/posts/2023/krita-in-stores-update/)
- **Aseprite** is source-available, not OSI open source: you may compile it for personal use but not redistribute the result. Paid binaries (about $20) sell on Steam and itch.io. ### Inferences
- If the web app is MIT and fully client-side, a paywall can be bypassed by anyone who reads the code. That's acceptable if the business is tips or "pay to support." It isn't acceptable for a hard paywall. Options in order of fit:
  1. Keep the web app MIT, monetise with tips plus an optional one-time "supporter" unlock (the Value Study tip-jar pattern).
  2. License the web app's repo AGPL (the ArtistAssistApp pattern) to stop closed commercial clones.
  3. Keep the web app's code in a separate proprietary or source-available repo while LeMuse stays MIT. Licensing is the owner's call, per CLAUDE.md.
- The friend's domain hosting raises brand/ownership questions (who owns the domain, analytics and revenue). Settle that in writing before launch. This is my inference and wasn't researched.
